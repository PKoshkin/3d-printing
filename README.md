# 3D-печать

Детали для печати у друга или в сервисе (Craftcloud). Модели пишутся кодом на
OpenSCAD: Павел описывает деталь словами, Claude её проектирует, скрипт собирает файлы
для печати и превью.

## Установка (один раз)

```bash
brew install --cask openscad@snapshot
```

```bash
git clone https://github.com/BelfrySCAD/BOSL2.git ~/Documents/OpenSCAD/libraries/BOSL2
```

Нужен именно snapshot: стабильная версия 2021.01 устарела и рендерит в разы
медленнее. Ещё нужен `uv` — он сам ставит зависимости скрипта сборки.

## Новая деталь

В Claude Code, открытом в этой папке, набери `/new-part` и опиши деталь: для чего она,
с чем стыкуется, какие есть замеры. Claude спросит недостающее, спроектирует деталь,
проверит сборку, напишет карточку для друга и откроет модель в OpenSCAD.

## Команды

```bash
make build PART=lamp-canopy                        # 3MF, STL, превью и проверки → parts/lamp-canopy/out/
make build PART=lamp-canopy TARGET=craftcloud-mjf  # то же под другой профиль печати → out/craftcloud-mjf/
make all                                           # то же для всех деталей
make open PART=lamp-canopy                         # открыть деталь в окне OpenSCAD
```

Сборка проверяет, что сетка замкнутая, OpenSCAD не выдал предупреждений и деталь
влезает в принтер своего профиля печати (`TARGETS` в `lib/printer.scad`): не влезает к
другу — ошибка, крупнее типичного принтера сервиса — предупреждение. Превью с четырёх
сторон лежит в `out/preview.png`.

## Смотреть и править

- В окне OpenSCAD включи **Design → Automatic Reload and Preview**: когда Claude
  правит файл, модель обновляется сама.
- **Window → Customizer** — параметры детали полями и ползунками. Поменял →
  F6 (рендер) → **File → Export → 3MF**.
- Первая группа в Customizer — **Где печатать**: принтер друга (FDM, до 20 см),
  Craftcloud FDM или Craftcloud нейлон PA12 (MJF/SLS). От неё зависят зазоры посадок и
  проверка размера.
- Как деталь будет печататься (слои, заполнение, поддержки, время, расход пластика), покажет
  слайсер: Bambu Studio, OrcaSlicer или PrusaSlicer, лучше тот же, что у друга.

## Что отправлять

- **Другу:** `out/<name>.3mf` (или `.stl`, если с 3MF что-то не так) и карточку
  `README.md` из папки детали. G-code не нужен: его друг сделает сам под свой принтер и
  пластик.
- **В сервис (Craftcloud):** загрузить `out/<name>.stl`, выбрать процесс, материал и
  отделку по карточке детали и вставить в заказ её комментарий для исполнителя.

## Раскладка

```
parts/<name>/<name>.scad   исходник детали
parts/<name>/README.md     карточка: что это и как печатать или заказать
parts/<name>/out/          результаты сборки (не в git)
lib/printer.scad           профили печати: где печатаем, размер, зазоры, стенки
tools/build.py             экспорт, превью, проверки
.claude/skills/new-part/   скилл /new-part: новая деталь от описания до файлов
```
