# 3D-печать: детали для принтеров друга

Павел описывает деталь словами (фото, эскиз, замеры), Claude проектирует её в
OpenSCAD и отдаёт файлы для печати. Павел смотрит модель в OpenSCAD или слайсере и
пересылает 3MF другу; друг сам готовит её к печати в своём слайсере. G-code не
делаем никогда: он привязан к принтеру, пластику и настройкам друга.

Павел не моделирует сам. Всё, что ему может понадобиться менять, должно быть
параметром в Customizer, а не правкой кода.

## Инструменты

- OpenSCAD snapshot (`brew install --cask openscad@snapshot`), бэкенд Manifold.
  Стабильную 2021.01 не использовать.
- BOSL2 в `~/Documents/OpenSCAD/libraries/BOSL2` (git clone, обновление —
  `git pull`), подключение `include <BOSL2/std.scad>`. Перед тем как использовать
  незнакомую функцию BOSL2, сверяться с её исходником там же, а не по памяти.
- `make build PART=<name>` запускает `tools/build.py` (зависимости ставит `uv`).

## Процесс

1. Уточнить, не угадывая: назначение, с чем деталь стыкуется и какие там размеры
   (замеры штангенциркулем, фото), нагрузка, материал, сколько штук. Нет размера —
   спросить.
2. Написать `parts/<name>/<name>.scad`. Модель сразу в ориентации печати: Z вверх,
   плоское основание на z=0. Параметры — в начале файла.
3. `make build PART=<name>` и обязательно посмотреть `out/preview.png`. Сверить
   отчёт: габариты, число тел (лишнее тело — висящий в воздухе кусок),
   замкнутость, предупреждения OpenSCAD. Чинить до того, как показывать Павлу.
4. Написать карточку `parts/<name>/README.md` по образцу `parts/tolerance-test`:
   назначение, файл и габариты, класс детали и рекомендация по печати (пластик,
   стенки, заполнение, модификаторы, ориентация, поддержки).
5. Показать Павлу превью, отчёт и что стоит проверить глазами
   (`make open PART=<name>`).

## Правила под FDM

- Единицы — мм; разрешение `$fa = 1; $fs = 0.25;` (уже есть в `lib/printer.scad`).
- Нависания не круче 45° от вертикали, мосты до ~10 мм. Иначе менять форму или
  ориентацию, а не рассчитывать на поддержки.
- Стенки ≥ 1.2 мм (3 линии по 0.4), мелкие элементы ≥ 0.8 мм.
- Посадки — зазоры из `lib/printer.scad` (калибруются пробником
  `parts/tolerance-test`), на сторону: отверстие = вал + 2 × зазор.
- Горизонтальные отверстия — каплевидные (`teardrop` в BOSL2), иначе свод провиснет.
- Нижние кромки, которые должны быть точными, — фаска 0.4–0.6 мм против «слоновьей
  ноги». Внутренние углы под нагрузкой — скругление.
- Слои — самое слабое направление: нагрузка должна идти вдоль слоёв, а не отрывать
  их друг от друга. Учитывать при выборе ориентации.
- Текст: высота ≥ 4 мм, `Liberation Sans:style=Bold`, гравировка 0.6 мм.
- Винты: M3 — сквозное Ø3.4; саморез в пластик — Ø2.5–2.8; термовставка — по её
  паспорту (обычно Ø4.0–4.2).

## Прочность и заполнение

Внутреннюю структуру детали (заполнение, infill) строит слайсер друга, а не модель:
`.scad` описывает сплошное тело, и внутри мы ничего не моделируем. Тонкие места, куда
помещаются только стенки, слайсер сам печатает сплошными. Наша часть — геометрия под
нагрузку и рекомендация по печати в карточке; окончательный профиль выбирает друг.

Рекомендация в карточке — по классу детали:

| Класс | Стенки | Заполнение |
|---|---|---|
| декор | 2 | 10–15 % |
| функциональная | 3–4 | 15–25 %, гироид |
| нагруженная | 4–6 | 25–40 %, гироид или кубическое |

- Прочность дают прежде всего стенки (периметры), а не процент заполнения:
  нагруженной детали — больше стенок. 100 % — только для маленьких сильно
  нагруженных деталей.
- Материал — туда, куда идёт нагрузка: бобышки вокруг винтов (наружный диаметр
  ≈ 2–2.5 диаметра винта), рёбра жёсткости вместо толстых сплошных массивов,
  скругления во внутренних углах.
- Месту, которому нужна плотность выше общей (под винт, ось, шарнир), —
  модификатор: отдельный модуль `modifier_<зона>()` в `.scad`, выгружается
  отдельным STL, друг добавляет его в слайсере как модификатор (например, со 100 %
  заполнения). Экспорта модификаторов в `tools/build.py` пока нет — добавить вместе
  с первой деталью, которой он нужен.
- Решётки и полости внутри модели не делать. Исключения — видимая решётка как
  элемент дизайна и фотополимерная печать (полая модель с дренажными отверстиями),
  и то только по договорённости с Павлом.

## Конвенции

- Код и комментарии — по-английски. Описания параметров Customizer, README и
  карточки — по-русски: их читает Павел.
- Параметры группировать `/* [Группа] */`, давать диапазон `// [min:step:max]`;
  служебные переменные — в `/* [Hidden] */`.
- Зависимости детали — только BOSL2 и `lib/printer.scad`
  (`include <../../lib/printer.scad>`).
- Коммитить только по просьбе Павла. В этом репозитории user.email локально
  выставлен на личный (koshkin.pasha@gmail.com) — глобальный рабочий сюда попасть
  не должен.
